# 🇰🇷 韩国干饭人通关密码本 (终极暴食版)

最全的韩国美食指南，支持中韩英对照、避雷吐槽、一键复制韩文点餐，助你通关韩国美食！

## 🌟 功能亮点

- **中韩英对照**：再也不怕看不懂菜单。
- **一键复制**：点击韩文名称即可复制，直接给店员看或在地图搜索。
- **避雷吐槽**：真实干饭人的心声，帮你避开雷区。
- **必吃清单**：点击爱心收藏你想吃的美食，生成你的专属清单。
- **打印支持**：支持将清单打印或保存为 PDF。

## 🚀 快速开始

1. 克隆或下载本项目。
2. 直接双击 `index.html` 即可在浏览器中运行。

## 🍱 分类指南

- **韩式餐厅**：正宗家常菜、定食、炒饭等。
- **咖啡甜点**：韩国最卷的咖啡文化和网红甜点。
- **肉食动物**：烤肉、炸鸡、生拌牛肉等。
- **汤汤水水**：大酱汤、参鸡汤、醒酒汤等。
- **面食碳水**：冷面、炸酱面、刀切面等。
- **街头小吃**：炒年糕、鱼饼、糖饼等。
- **适合喝一杯**：下酒菜、米酒、烧酒。
- **便利店寻宝**：便利店必买好物。
